# Service Card Images (Optional)

The site currently uses Unsplash images. To use your own images, replace the URLs in `index.html` with paths to files in this folder:

| File | Service | Suggested content |
|------|---------|-------------------|
| individual.jpg | Individual Counselling | Calm therapy space, meditation, person in peaceful setting |
| child-adolescent.jpg | Child & Adolescent Support | Parent and child, child in supportive setting |
| couple-family.jpg | Couple & Family Counselling | Family or couple together, group connection |
| assessments.jpg | Psychological Assessments | Professional/thoughtful, document or consultation |
| corporate.jpg | Corporate Wellness | Office, workplace wellness, team collaboration |

Recommended size: 600×340px or 16:9 aspect ratio.
